## 🎨 Design System

### Color Palette
- **Background:** Deep black (#000000) with dark blue undertones
- **Primary Gradient:** Purple (#8B5CF6) to Red (#EF4444)
- **Accent:** Electric purple (#A855F7)
- **Text:** White (#FFFFFF) primary, Gray (#9CA3AF) secondary
- **Cards:** Transparent black with frosted glass effect

### Typography
- **Headings:** Outfit font family (Bold, Black weights)
- **Body:** Manrope font family (Regular, Medium weights)
- **Size Scale:** 
  - H1: 60px (Desktop), 36px (Mobile)
  - H2: 32px (Desktop), 24px (Mobile)
  - Body: 16px

### UI Components
- **Buttons:** Rounded corners (12px), gradient fills
- **Cards:** 16px border radius, glass morphism effects
- **Shadows:** Soft glows with purple tints
- **Icons:** Lucide icons with custom accent colors

## 🎬 AI Features Highlighted

### Core Capabilities
1. **Whisper Speech-to-Text:** Automatic language detection and transcription
2. **GPT-4o Translation:** Conversational, cinema-style translations for South Indian languages
3. **OpenAI TTS:** Natural voice synthesis
4. **Multi-Audio Track Output:** Original + dubbed audio in single MP4 file

### Supported Languages
- Tamil (தமிழ்) - Modern conversational style
- Telugu (తెలుగు) - Natural spoken dialect
- Malayalam (മലയാളം) - Authentic colloquial
- Kannada (ಕನ್ನಡ) - Cinema-style dialogue
- Plus 11 additional languages (English, Spanish, French, German, Hindi, etc.)
